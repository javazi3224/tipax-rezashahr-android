# اپ اندروید تیپاکس شعبه رضاشهر

این یه اپ اندروید ساده‌ست که دور همین سایت (`tipaxrezashahr.ir`) یه پوسته (WebView) کشیده - یعنی همون سایتیه که الان تو مرورگر کار می‌کنی، فقط به شکل یه اپ جداگانه با آیکون خودش رو گوشی. هر تغییری رو خود سایت بدی (هر فیچر جدید، هر اصلاحی)، همینجا هم خودکار اعمال می‌شه - نیازی به آپدیت اپ نیست.

چیزهایی که اضافه بر یه WebView ساده بهش اضافه شده:
- **آپلود فایل/عکس** - برای فرم‌هایی مثل آپلود اکسل کدهای رهگیری یا عکس فیش.
- **دانلود فایل** - اکسل/PDF گزارش‌ها با همون نشست ورودی کاربر (کوکی) دانلود می‌شه و تو پوشه Download گوشی ذخیره می‌شه.
- **دکمه برگشت گوشی** - اول تو تاریخچه‌ی سایت برمی‌گرده عقب، نه این‌که مستقیم از اپ خارج بشه.
- **Pull-to-refresh** - کشیدن از بالا برای رفرش صفحه.
- **صفحه‌ی قطع اینترنت** - با دکمه‌ی تلاش دوباره.

## این پروژه چیه و چی نیست

این یه پروژه‌ی کامل گریدل/اندرویده (کد کاتلین + منابع + آیکون از لوگوی خودتون ساخته شده)، آماده‌ی باز کردن تو Android Studio. **فایل APK نصب‌شدنی همراهش نیست** - چون ساختنش به Android SDK نیاز داره که تو محیط من (که فقط یه سرور ابریه، نه یه کامپیوتر با اندروید استودیو) در دسترس نیست. برای گرفتن فایل APK، یکی از این دو راه رو برو:

### راه ۱ - اندروید استودیو (ساده‌ترین راه)
1. [Android Studio](https://developer.android.com/studio) رو نصب کن (رایگانه).
2. از منوی `File > Open`، همین پوشه (`tipax-android`) رو باز کن.
3. بذار خودش Gradle Sync کنه (بار اول چند دقیقه طول می‌کشه، چون باید Android SDK و وابستگی‌ها رو دانلود کنه).
4. از منوی `Build > Build Bundle(s) / APK(s) > Build APK(s)` بزن.
5. فایل APK نهایی تو مسیر `app/build/outputs/apk/debug/app-debug.apk` ساخته می‌شه - همینو رو گوشیت کپی کن و نصب کن (باید تو تنظیمات گوشی «نصب از منابع ناشناس» رو برای همون اپی که باهاش فایل رو باز می‌کنی فعال کنی).

### راه ۲ - گیت‌هاب اکشنز (بدون نصب هیچی رو کامپیوتر خودت)
یه فایل `.github/workflows/build-apk.yml` همراه این پروژه هست. اگه این پوشه رو (مثلاً با گیت‌هاب دسکتاپ یا حتی آپلود مستقیم فایل‌ها از رابط وب گیت‌هاب) تو یه ریپازیتوری گیت‌هاب بذاری، خودش خودکار پروژه رو می‌سازه و فایل APK رو به‌عنوان «Artifact» قابل دانلود آماده می‌کنه - کاملاً رایگان، بدون نیاز به کامپیوتر قوی یا نصب اندروید استودیو.

## قبل از انتشار واقعی (نصب رو گوشی‌های خودتون/کارمندها کافیه، ولی برای Google Play لازمه)

- **امضای اپ (signing)**: فایل APK ساخته‌شده با روش بالا یه نسخه‌ی «debug» (آزمایشی) هست که رو هر گوشی‌ای مستقیم نصب می‌شه ولی تو Google Play قابل انتشار نیست. برای انتشار رسمی باید یه «keystore» بسازی و تنظیمات امضا رو تو `app/build.gradle` اضافه کنی - اندروید استودیو خودش تو منوی `Build > Generate Signed Bundle / APK` این کارو قدم‌به‌قدم انجام می‌ده.
- **HTTPS**: چون سایت فعلاً فقط HTTP داره (بدون SSL)، تو `app/src/main/res/xml/network_security_config.xml` یه استثنا برای همین دامنه گذاشته شده تا اندروید ترافیک HTTP رو بلاک نکنه. اگه بعداً سایت گواهی SSL گرفت، بهتره آدرس تو `MainActivity.kt` (ثابت `BASE_URL`) رو به `https://` تغییر بدی و اون استثنا رو هم برداری.
- **آیکون اپ**: از همون لوگوی سایت (`logo.png`) ساخته شده. اگه خواستی عوضش کنی، فایل‌های `app/src/main/res/mipmap-*/ic_launcher.png` رو جایگزین کن.

## ساختار پروژه
```
tipax-android/
  app/
    src/main/
      java/ir/tipaxrezashahr/app/MainActivity.kt   <- کل منطق اپ همینجاست
      res/layout/activity_main.xml                  <- چیدمان صفحه (WebView + نوار پیشرفت + صفحه آفلاین)
      res/values/                                    <- رنگ‌ها، متن‌ها، تم
      res/mipmap-*/                                  <- آیکون اپ تو سایزهای مختلف
      AndroidManifest.xml
  build.gradle, settings.gradle, gradle.properties   <- تنظیمات گریدل
  .github/workflows/build-apk.yml                    <- ساخت خودکار APK با گیت‌هاب اکشنز
```
